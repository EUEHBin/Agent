# 二、骑行台第三条

今年冬天我入了这款迈金T600ECO骑行台，并且已经使用了几个月的时间，今天来给大家分享一些使用和训练的技巧。

在开始训练之前呢，好的准备是能让你事半功倍的，并且可以坚持的更久。

首先是环境的布置：选择平整稳固的地面放置骑行台，铺上防滑垫和毛巾，起到防滑吸汗的作用，通风也是很重要的，冬季室内训练会大量的出汗，可以在前面放一个风扇来更好的散热，提升整体的训练、运动表现。

往往骑骑行台是比较枯燥的，所以每次训练的时间不用过长，高质量的训练通常在60分钟到90分钟就能起到很好的效果，并且也能够快速的恢复状态。

 

我用的这款骑行台是迈金的T600Eco，购买后赠送了顽鹿竞技会员，连接上骑行台之后，建议大家先进行基础测试，了解自己目前的骑行能力。

玩鹿竞技里面有很多的课程，大家可以根据自己测试的结果，针对性的去选择训练内容，比如踏频训练、有氧训练、爬坡训练这些。

T600Eco这款骑行台是支持左右平衡和踩踏平顺度的，在骑行的过程中，能够帮我们发现像左右腿发力不均，“猛踩”式蹬踏这些问题。我们可以根据这些数据，针对性的进行改善，从而提升踩踏效率。

并且这款骑行台是支持路感模拟的，搭配上各种地图，让骑行更沉浸式，减少枯燥感。

# 七、手套分享视频

选择骑行手套应该注意哪些点？

这些骑行手套都是我戴过的，今天来给大家分享一下实际的佩戴体验，给大家避坑一些不好的设计。

 

第一款是一个薄款的长指手套，价格是二十多，15度左右佩戴，掌心加了硅胶掌垫，手指这部位的触屏也很灵敏，性价比还是很高的，但是手指尖这个部位处理的不是很完美，这个加高的设计，缝线都在手指尖这，如果戴的比较紧的话，会有这种顶到指甲缝的感觉。

 

第二款是塔斯队长这个，佩戴上很舒服，碗口做了松紧的设计，里面加了绒，10度左右的温度佩戴是没有问题的，触屏同样很灵敏，但是呢，他这个掌心没有加减震垫，只加了这种防滑垫。

 

第三款是西骑者这个薄绒款，整体的配置和感受和塔司队长的基本上一样，但是他这个手指部位加了一些防滑的焦点，防滑效果要稍好一些。

 

第四款是这个博顿薄绒款，佩戴到10度左右，这个就很全面了，掌心麂皮绒，加了掌垫，背面是速度游泳面料，佩戴上很舒适，触屏也很灵敏。很全面，就是价格高点，60多。

 

第五款是这个博顿的加绒手套，0度以上戴，保暖没问题，手腕做了收口，而且做了一个防丢的设计，佩戴舒适，触屏灵敏，但是掌心位置没加掌垫，只有防滑条。

 

然后是西骑者这个厚款，对比博顿的这个绒颗粒更粗一些，他的这个三根手指都是可以触屏的，其他的佩戴感受和博顿厚款差不多。

 

最后是铭胜的厚款，这个感觉是0度比较全面的手套，掌心加了80密度的掌垫，做了收口设计，大拇指做了擦汗设计，但是这个指尖的触屏使用上是没有博顿的灵敏的，使用倒是没有问题，但是他家这个尺码感觉是有问题的，我掌宽是9，这个是M码标注可以用到9.5，但是我戴上之后感觉会有点紧，佩戴的整体感觉还是不错的。

 

大家在选手套的时候，长指的，特别是冬季戴的，一定要选择带触屏的，这样操作手机就不需要摘手套，而且注意要选择带掌垫的，能减少骑行过程中的手疼手麻问题。

 

 

# 八、头部保暖分享

冬季骑车头部不知道怎么保暖的，今天根据我自己的经验，给大家分享一下。

基本上可以分为两类，一体式的和分体式的。这两种各有优缺点。

 

首先说说分体式的，就是抓绒小帽+口罩面罩二合一+脖套的组合，好处是每个部位是分开的，根据温度可以自由搭配，自由调节。缺点就是选款的时候要选好，不然有的搭配中间空隙比较大，而且要戴的东西有点多，可能会感觉有些累赘。

 

再说说一体的，好处就是把小帽、口罩、面罩、脖套四合一了，出门戴这一个就够了。缺点嘛，是一体的，也就是说戴就得全戴，拆分不开，口鼻这个位置倒是是可以拉下来的。

 

我自己是把这些都准备了，根据当天的温度自己去搭配。

 

选择这些东西的时候也有几个需要注意的点。

首先是这个小帽，要选加绒的，但是外层的这个面料一定要选择透气的。

口罩要选择带呼吸孔的，这样才不会影响咱们呼吸。

耳朵这个部位，有的是小帽做加长挂耳，有的是口罩做了，这个大家选择的时候不要冲突。

大部分的头套也都在口鼻位置做了特殊的设计，不会影响呼吸，面料基本上分为两类，科技纤维和羊毛的。

科技纤维的比较便宜，二三十，但是会有冷热不均的这个缺点，佩戴起来舒适度一般。

像这种美利奴羊毛的，保暖更均衡，也不会扎脸，立体拼接也比较舒适。但是价格基本都在百元左右了。

 

每个人的感官和所在的环境都不一样，所以怎么选择就要看自己了，但是如果冬季你依然外出骑行，保暖措施一定要做好，特别是头部的保暖。

# 十九、迈金电变（车装好之后拍摄）

国产电变到底行不行？迈金的QED电变到底怎么样？值不值得购买？

车上的这套QED电变已经使用了一段时间了，今天来给大家分享一下整体的感受和体验。

 

#### 首先咱们来聊聊兼容性和变速体验：

我目前的传动搭配是：105的牙盘，UT的飞轮，加上DYC的链条，一套比较常见的组合，QED接入之后，兼容性完全没问题，日常使用中变速响应十分丝滑。有一个需要注意的是现在的QED后拨是不支持直装尾勾的，这个我咨询过客服，后续会进行配件上的支持。

 

变速逻辑和禧玛诺完全相同，如果你之前使用的是禧玛诺，是可以无缝切换的，具体到响应速度上，前拨的响应速度我感觉介于105和UT之间，而后拨的响应速度很利落，是可以和UT媲美的。这样的速度，无论是平路巡航还是爬坡时的连续变档，都是足够可靠的，不会有拖沓感。

 

#### 接下来聊聊细节和使用质感：

手变头和后拨鸡腿都用了碳纤维材质，这让整套电变的重量控制得不错。只有1100多克。

电变按钮的触感很清脆，有点像青轴机械键盘的感觉 ，按下去有明确的反馈，操作起来很有确认感。手变侧面的两个自定义按键，可以通过顽鹿运动APP的“智联助手”进行功能自定义。比如设置成控制码表的响铃、或开关车灯，这种设备联动的“可玩性”让我觉得它不只是个变速工具，更是个有趣的智能终端。

 

#### 再说说安装和售后：

安装流程和禧玛诺电变大同小异。比较省心的是，购买QED后，迈金会分配你附近的门店免费安装。这对于不想自己折腾，或者对安装精度有较高要求的用户来说，是个很实际的服务。

 

#### 最后说说值不值得入手：

经过这段时间的使用，我觉得迈金做产品是真正在用心的。作为国产品牌，敢于挑战电变这样的高技术领域，并且交出完成度如此高的产品，本身就值得肯定。

 

如果你正在考虑升级电变，或者打算DIY一辆新车，预算又希望在亲民区间，那么迈金QED绝对是一个值得你放入备选清单的选择。它在核心的变速性能上做到了贴近国际大牌的体验，同时在一些智能化细节和价格上，展现出了国产产品独特的优势。

我们可以对国产品牌报以更多的信心和期待。毕竟，有竞争，才有进步；有尝试，才有突破。

# 三、迈金套件介绍（8月份要发一条介绍）

如果把机械变速升级成电子变速，到底能有什么新体验？

今天以我手里的这套迈金的QED电变为例，给大家分享几个很实用，也比较有意思的功能。

 

相信前拨蹭链这个问题大家都遇到过，在极限档位搭配的情况下，比如大盘对大飞，小盘对小飞的时候，机械变速会发生蹭前拨的情况，这个时候我们可以通过机械的半档来解决这个问题。

而在迈金的QED电变上，是有一个前拨随动的功能，当我们进入极限档位的时候，前拨会进行微调，避免发生前拨蹭链的情况。这个随动功能是自动的，不用我们自己去按键控制。

 

大家是不是在骑行的过程中也会遇到踏空或者突然踩踏费力的情况，这都和档位切换不合理有关，有时候这些行为是很危险的，可能会导致摔车。

而在迈金的QED电变上，可以通过序列变速模式很好的解决这个问题，先在APP上预设好档位，在我们调节后拨档位的时候，达到咱们得预设值，前拨会随后拨自动调整，消除类似踏空这类的危险问题。另外他还有一个补偿模式，同样是提前在APP上设置好档位，只需要操作前拨，后拨会根据预设值，切换到对应的档位。这两个模式大家可以根据自己的骑行习惯自定义档位，还是很有用的。

 

QED电变的左右手变头一共有6个按键，都是可以在app上自定义功能的，内侧的这两个按键我们一般会用来控制车灯，给码表翻页这些，除了支持迈金自家的码表外，对佳明和wahoo也做了支持。

 

目前在国产电变领域，迈金还是很有创新和亮点的，后续装车之后再来给大家分享一下这套电变的深度使用感受。
