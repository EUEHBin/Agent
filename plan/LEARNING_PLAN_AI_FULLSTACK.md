## 怎么学：Cursor vs 手写

同 Node 计划精神，换成 Python 表述：

| 层级 | 内容 | 标准 |
| --- | --- | --- |
| **必须能自己重写** | 请求进 FastAPI → 依赖注入 → 落库；**SSE 流式**（生成器/`StreamingResponse`、前端 ReadableStream、Abort）；RAG 切分/检索/Grounding | 关掉 Cursor 能写出核心路径 |
| **生成但必须读懂** | CRUD、模型定义、Vue 骨架 | 能指出错了会怎样 |
| **可生成** | 测试、Docker、README、类型 | 能跑即可 |

循环：先自己写一版再让 Cursor 改；核心周周末空文件重写；记下 Cursor 写错的例子（面试用）。
