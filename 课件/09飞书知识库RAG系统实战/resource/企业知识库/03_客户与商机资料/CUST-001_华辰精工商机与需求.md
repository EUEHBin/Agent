## 商机信息

客户编号为 C-HC，客户名称为华辰精工，内部简称“华辰”。商机编号 OPP-HC-01，项目名称为工艺文档知识助手。客户希望让工程师更快找到历史工艺说明和异常处理记录，减少向老师傅反复询问的时间。

客户信息主管许航负责技术验收，采购负责人顾玥确认商务条件，生产副总贺清批准采购预算。销售负责人林悦，售前负责人周衡。

## 七月初的需求

2026-07-08 的访谈口径为四十名注册用户、峰值四个同时处理的请求，输入约 2048 tokens，使用星语 32B Q4。预算为 40 万元。客户现有工务通 2.3，希望保留原系统。

根据当时的需求，售前提交了 SOL-001。该方案属于历史方案，不代表八月后的最终配置。

## 八月确认的需求

2026-08-12，许航确认需要把质检组加入首期项目，并将检索得到的工艺背景一起传给模型。以下要求替代七月口径：

| 项目 | 当前要求 |
| --- | --- |
| 首期注册用户 | 60 人 |
| 峰值同时处理的请求数 | 8 |
| 模型 | 星语 32B v1 Q4 |
| 模型输入长度 | 4096 tokens |
| 模型输出长度 | 256 tokens |
| 模型阶段整机合计输出速率 | 不低于 96 tokens/s |
| 模型阶段首 token 延迟 P95 | 不高于 2.5 秒 |
| 完整应用的首 token 延迟 P95 | 不高于 4 秒，客户现场另测 |
| 业务系统 | 工务通 2.3，本期不升级 |
| 部署要求 | 内网部署，推理与文档内容不得调用外部模型服务 |
| 首期总预算 | 42 万元，包含设备、必要适配和一次集成 |

预算未包含未来延长维保，三年后的服务需要另议。客户没有承诺在本期升级工务通。

## 待确认事项

客户还未提供正式数据样本和网络证书配置。售前需验证完整应用延迟及旧版接口在客户网络中的表现。现阶段实验室性能不能直接作为最终验收结论。

客户询问“一百个人以后能不能用”，指的是未来注册用户规模，尚未给出未来并发负载，不是本期已确认的验收要求。
