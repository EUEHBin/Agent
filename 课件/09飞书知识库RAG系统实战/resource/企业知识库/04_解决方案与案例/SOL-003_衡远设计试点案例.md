# 衡远设计资料助手试点案例

文档编号：SOL-003  
版本：1.0  
记录日期：2026-08-10  
负责人：售前 周衡  
状态：试点完成 未形成采购合同  
阅读范围：销售与售前

## 试点背景

衡远设计希望减少工程师在历史方案与评审意见之间来回查找的时间。客户编号 C-HY，商机 OPP-HY-01，借用部署编号 DEP-HY-01。

本次使用 CFG-A400-4、引擎 3.2.0、星语 70B v1 Q4 和 COMP-GWT-S30 2.0，对接工务通 3.0。资料范围为客户提供的去标识样本文档，未覆盖全部生产资料。

## 工作流程

工程师输入评审问题，资料助手检索相关方案与评审记录，将证据交给模型生成摘要，并展示来源。没有找到证据的问题，需要工程师补充资料或人工核实。

试点性能负载为四个同时处理的请求，模型输入 4096 tokens、输出 256 tokens。TEST-002 的 A400-4K-4 是相应模型基准。试点完整应用的首 token 延迟 P95 记录为 3.8 秒，包含检索和接口过程，不能与模型阶段的 1.9 秒混为同一个指标。

## 使用观察

试点选取二十个资料查找任务，记录人工独立查找和使用助手辅助时的完成时间中位数，分别为二十八分钟和十九分钟。任务数量有限，参与者会复核答案；这些观察不能推算成整个公司固定比例的降本结果。

客户认可跨文档摘要与来源定位，但指出三份旧版方案与新版评审要求容易混淆，要求正式系统明确标注资料日期与适用版本。

## 可引用范围

销售可以说明该客户完成了指定配置与 Q4 模型的试点，并介绍资料查找流程。借用设备未形成采购合同，不能称作已经成交的正式生产客户。

本案例没有星语 70B FP16 的效果和性能结论，也没有八请求、16000 tokens 输入的验收结果。客户后来新增的采购要求见 CUST-003。
